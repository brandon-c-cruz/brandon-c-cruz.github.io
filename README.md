# Brandon Cruz | Personal Portfolio

Personal portfolio website for Brandon Cruz, Finance student at Rutgers Business School (Class of 2028) and former M&A Summer Analyst.

**Live site:** hosted with GitHub Pages from this repository.

## What's inside

| File | Purpose |
| --- | --- |
| `index.html` | Home page: personal statement, skills, projects, experience, contact |
| `lbo-calculator.html` | Project 1: interactive LBO returns calculator (live demo, plain JavaScript) |
| `projects/pipeline-database.html` | Project 2: recruiting and deal pipeline database, with query results |
| `projects/pipeline-database.sql` | Full MySQL script: schema, sample data and analytical queries |
| `style.css` | Shared styles (responsive, with automatic dark mode) |

Built with HTML, CSS and JavaScript. No frameworks or build step.
